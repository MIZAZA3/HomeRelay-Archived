# HomeRelay — 家宽出口转发与节点管理（公开退役归档）

**状态：已停止开发，并于 2026-11-01 从原服务器和网页卸载。**

把经过授权的朋友电脑作为网络出口：朋友点击“启动转发”向服务器报到，管理员在网页选择启用节点，使用者用 SSTap / FlClash 的标准 Shadowsocks 配置连接。

项目的云端 TCP/UDP 24443 放行规则也已删除；原网站、管理 SSH 和非项目规则保留。

这是源码与研发记录归档，不是一个已经证明稳定可用的一键部署项目。
此前独立客户端协议测试通过，但用户虚拟机内 SSTap / 游戏登录器仍有真实故障；
不能将 TCP/UDP 探测成功等同于实机体验或长期稳定。

## 主要功能

1. **出口端一键报到**：Windows 端生成独立设备身份，不提前建名单，新设备默认待启用。
2. **网页节点管理**：在线状态、备注、最后心跳、连接来源、出口 IP、TCP/UDP 检测；启用、闲置、拒绝/停用。
3. **独立使用密码**：每节点随机/自定义密码、更换与撤销，旧凭据和连接按版本失效。
4. **标准加密入口**：最终 V4 提供 Shadowsocks `aes-256-gcm` TCP/UDP、SSTap 链接和 FlClash YAML，不需要旧接收器。
5. **双向限速**：每节点上传/下载分别设置，所有节点每方向合计仍受 256 KiB/s 保守总上限保护。
6. **运行隔离**：解析后公网目标校验、禁止朋友内网/服务器自身、权限/并发/资源/UID 出站限制。
7. **历史连接器留档**：本机 SOCKS5/HTTP/SS、一个/多个 EXE、独立代理浏览器、默认关闭的手动全局模式；不是最终 V4 的必需组件。

## 链路

```text
使用者 SSTap / FlClash
  → 标准 Shadowsocks aes-256-gcm（TCP + UDP）
  → 公网中转 GOST → 节点鉴权 / 限速 / 公网目标闸门
  → 朋友主动建立的 SSH 反向通道
  → 朋友电脑本机 GOST → 朋友宽带 → 目标网站/应用

朋友电脑 → HTTPS 注册/心跳 → 控制器
管理员   → HTTPS 管理面板 → 受限网关 → 控制器
```

朋友通常不需要公网入站 IP 或路由器端口映射；中转需要能被朋友访问的 HTTPS 和受限 SSH。UDP 在服务器到朋友这一段经 UDP-over-TCP/SSH 承载，可能有队头阻塞，不是全程原生 UDP。

## 下载源码

```bash
git clone https://github.com/MIZAZA3/HomeRelay-Archived.git
cd HomeRelay-Archived
```

也可以点 **Code → Download ZIP**。仓库不含开箱即用 EXE、可用节点、真实凭据或通用冷启动安装器。先阅读文档与运行不联网单元，不要盲跑历史发布/退役脚本。示例 `203.0.113.20`、`203.0.113.30`、`relay.example.invalid` 不提供服务。

自动报到不代表自动批准/开云端口；不承诺任意 EXE 必定被接管、任意规模、游戏稳定性、隐藏所有目标信息或“没有漏洞”。公开源码不会恢复原服务器部署，也不会修改 FlClash。

## 不包含

- 登录私钥、真实密码/令牌、设备身份、运行数据库、生产配置及私人备份。
- 浏览器资料、云账号信息、网站业务数据或其他项目。
- SSTap 安装包、驱动、第三方 EXE/DLL/SYS 或其他二进制安装包。

服务器地址、域名、节点编号和家宽出口信息已替换为文档示例。
旧源码中的注册令牌和主机公钥占位符必须自行重新生成，不能直接使用。
历史发布/回退脚本绑定当时特定前像，不应不经审查直接运行；归档不会自动部署。

**V4.5 原型没有发布到原服务器，也没有经过用户虚拟机的最终验收。**
它完成了隔离/单元回归，但用户随后要求撤销项目；不能把它描述成已上线解决方案。
第三方组件保留原许可证；本次没有额外声明整个项目的新开源许可证。
