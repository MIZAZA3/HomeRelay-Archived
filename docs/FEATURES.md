# 功能清单与架构

[首页](../README.md) · [使用手册](USAGE.md) · [构建部署](BUILD_AND_DEPLOY.md)

本页描述归档源码和历史实现，不表示原服务仍在线。V4.4 是最后部署阶段；`current/` 另含未上线的 V4.5 原型。

## 1. 三种角色

| 角色 | 职责 |
|---|---|
| 出口方/朋友 | Windows 上启动出口端，保持网络与窗口运行；不填使用者密码，不手动导出连接包 |
| 管理员 | 部署服务器，审核节点，开通端口，管理状态/密码/限速；不交出管理 SSH 私钥 |
| 使用方 | 通过 SS 参数/链接/YAML 配置 SSTap / FlClash；最终 V4 不运行旧接收器 |

## 2. 出口端

- 首次生成设备 ID、随机秘密与独立 SSH 密钥；设备身份以 Windows DPAPI CurrentUser 保护。
- HTTPS 注册、约每 10 秒心跳，新节点默认 `pending`；不要求管理员提前建名单。
- 获准后本机 GOST 提供受认证的 loopback SOCKS5，OpenSSH 建立受限反向 TCP 通道。
- 尝试物理以太网/Wi-Fi，排除部分虚拟网卡；不是对所有 TUN/热点/防火墙环境都兼容的保证。
- 退出工具停止其子进程和转发；不设系统代理、不装虚拟网卡、不设开机自启。
- 连续轮询失败或子进程退出会尝试重连；旧 SSH 假在线但数据链卡死仍是未完全验收的问题。

源码：[Agent.cs](../windows/agent-and-connector-v2/source/Agent.cs)、[Common.cs](../windows/agent-and-connector-v2/source/Common.cs)、[NetBridge.cs](../windows/agent-and-connector-v2/source/NetBridge.cs)。

## 3. 网页面板

| 功能 | 行为/边界 |
|---|---|
| 自动发现 | 注册即出现，默认待审核；不是任何公网访问都能直接转发 |
| 概览/信息 | 登记、在线、待启用、已启用；备注、连接来源、最后心跳、通道、出口检测结果 |
| 启用 | 在线、凭据与端口都满足条件时承接流量 |
| 闲置 | 停止该节点已有/新转发；保持报到，可保留 SSH 通道 |
| 拒绝/停用 | 停流量，朋友轮询后停止通道；保留设备记录，不是删除 |
| 备注 | 改名不改设备身份 |
| TCP/UDP检测 | HTTPS 出口及 UDP DNS 探测，不等于所有网站/游戏可用 |
| 参数导出 | 服务器、端口、算法、密码；SSTap链接和FlClash YAML |
| 密码管理 | 自定义/随机、更换、撤销、期望版本检查 |
| 节点限速 | 上传/下载分别设置，保存后热应用 |

管理口令、节点使用密码、设备秘密、SSH身份彼此不同。网关只监听 loopback，由 HTTPS 反向代理提供访问，不裸露内部管理端口。

源码：[页面](../current/server/panel.html)、[前端](../current/server/app.js)、[网关](../current/server/web_gateway.py)、[控制器](../current/server/controller.py)。

## 4. 协议和密码

| 环节 | 最终 V4 实现 |
|---|---|
| 使用方→中转 | 标准 SS `aes-256-gcm`，TCP/UDP 分别由 GOST SS/SSU 监听 |
| 中转内部 | loopback代次鉴权、公网目标校验、双层限速 |
| 中转→朋友 | SSH反向TCP，承载TCP和GOST UDP-over-TCP |
| 朋友→目标 | 原目标协议；HTTPS靠TLS保护，普通HTTP不自动变成HTTPS |

公网端口不是裸 SOCKS5/HTTP，也不是最早的mTLS入口。SS不填用户名，每节点独立端口和密码。中转与出口仍需信任，不能承诺把全部目标信息对它们隐藏。

密码支持8–128字符、拒绝控制字符/当前及近期历史值；历史只保留有限HMAC指纹。自定义密码以Fernet认证加密保存，密钥绑定master/节点/代次；master泄露不在该保护之外。更换/撤销使本节点旧配置和连接失效，不重启其它节点密码。已下载YAML不会被远程抹去。

## 5. 速度与容量

- 上传/下载以**使用方**为视角，单位KiB/s；`1–256`为节点限额，`0`继承总限制，不是无限速。
- 同节点所有TCP/UDP连接合计计费；全部节点每方向合计256KiB/s，约2.1Mbps，不是每人各256。
- 单节点32 / 全局64数据连接；默认设备槽位32，与连接数不同。
- 总上限是原服务器保守保护，不代表朋友宽带只有这么快。提升需审查代码、校验、数据库约束、前端和资源容量，不只改输入框。
- 不含按用户分账、流量套餐、按使用者独立配额、运营商计费或高可用集群。

## 6. 隔离与安全设计

- 只允许公网目标；域名全部解析结果校验，混入禁止地址即拒绝，固定数字IP给朋友，避免二次解析绕过。
- 拒绝私网/共享/回环/链路本地/元数据/组播/保留范围、相关转换前缀及服务器自身；无服务器直出回退。
- 不能通过此服务访问朋友路由器、NAS或服务器管理面板。
- 受限UID、专用IPv4/IPv6出站链、CPU/内存/FD/任务/并发限制。
- 网页会话、CSRF、同源校验、限流、no-store；同域名路径不是独立安全来源。
- 这些是实现和测试过的保护，不是无漏洞证明或完整渗透审计。

## 7. 版本与历史连接器

| 版本 | 内容/定位 |
|---|---|
| V2 | 自动报到、管理面板、本机SOCKS5/HTTP/SS；出口端源码仍是V4基础，旧接收器路线已停 |
| V3.0/3.0.1 | 一个/多个EXE、手动全局TCP/UDP；不保证任意程序兼容 |
| V3.0.2 | Chromium独立资料目录+原生HTTP代理，限制非代理WebRTC UDP/QUIC；不是系统级强制防泄漏 |
| V4.0 | 标准SS公网入口，SSTap/FlClash直连中转，废弃旧接收器 |
| V4.1 | 自定义节点密码 |
| V4.2 | 节点双向限速、解析后公网目标保护 |
| V4.3 | DNS有界排队/合并、UDP空闲和容量调整 |
| V4.4 | DNS会话容量回收、SQLite连接关闭、并发边界；最后部署阶段，实机长期稳定性未达标 |
| V4.5草稿 | 数据链健康/隔离/恢复研究，仅隔离/单元测试，未上线 |

未提供：自动开云安全组、任意EXE强制代理、全程原生UDP、任意并发、稳定游戏加速、出口方看不到全部目标、全链路匿名或“零漏洞”。
