# HomeRelay Direct V4.3

2026-11-01，北京时间。已定向发布到现有 Ubuntu 服务器；朋友通用出口端不变，旧接收器退出使用链路。

## V4.3 稳定性补丁

- DNS 改为最多 64 个待处理名字的有界队列，实际并发仍为 4；同节点同域名共享在途查询，一个请求取消不会打断其他请求。排队 + 解析合计等待上限 8 秒，原公网目标校验 / IP 固定继续执行。
- UDP 首字节的空闲等待改为 180 秒，半包仍限制 15 秒，GOST SS UDP 会话 TTL 从 30 调到 120 秒；不是无限保活。
- 每节点并发从 16 调为 32，全部节点合计仍 64；CPU / 内存 / FD 保护和全局每方向 256 KiB/s 不变。
- 只更新服务器 3 个文件、只重启 controller；网页布局仍为 V4.2。**不用重装朋友出口端，不用换密码；SSTap 断开重连一次即可使用新后端。**
- 106 项隔离集成 + 14 项稳定性单元通过，含 20 条标准 SS 并发与 UDP 空闲后复用；公网标准 SS TCP / UDP 通过，同一 UDP socket / SOCKS 控制连接空闲 35 秒后首个 DNS 查询成功。
- 没有声称所有网站已通。`ip77.net` / `myip.ipip.net` 实测两轮 HTTPS 正常；`api.ipify.org` 仍提前结束 TLS，直接朋友通道对照也有该问题；`4.ipw.cn` 的 HTTPS 尝试亦未成功。保留原始失败，未将其算成通过，未完成实际 SSTap TAP 浏览器 / 游戏验收。
- 区域出口加密 DNS 的额外原型实测仍超时，**没有发布**；生产仍由中转解析、校验全部候选并固定公网 IP，不降低内网防护。具体见 [STABILITY_V43.md](STABILITY_V43.md)。

## 使用

1. 朋友保持原“通用出口端”，点击“启动转发”。不需要重装、填写客户名单或发连接包。
2. 打开 [原管理面板](https://relay.example.invalid/relay-admin/)，用原管理口令登录。
3. 对已开通的节点点“启用”。要手动指定密码，点“设置 / 更换节点密码”，输入两次新密码后点“保存自定义密码”；也可选“随机生成并更换”。仅打开窗口不会换密，查看参数中的只读密码框不能直接修改后端。
4. 保存后再点“查看 / 导出 SSTap · FlClash”。
5. **SSTap 1.0.9.7** 选 **Shadowsocks**，填面板里的服务器、端口、`aes-256-gcm` 和节点密码；不填用户名。可复制 SSTap 导入链接；若界面提供协议 / 混淆，使用 `origin` / `plain`，不启用额外插件。
6. **FlClash** 下载面板的 YAML，手动导入为独立配置，再选择 HomeRelay。导出配置不打开 TUN、不允许局域网接入、不配置 DIRECT 回落；不会自动覆盖现有配置、订阅或规则。已有本地端口安排不同，可自行调整 YAML 的 `mixed-port`。
7. 点节点的 **“设置最高网速”**，分别填写最高上传 / 下载，单位 **KiB/s**。`1–256` 是该节点的上限，`0` 继承服务器总上限，**不是不限速**；点“保存限速”后对现有与新连接实时生效。“两项恢复继承”只改表单，仍需保存。

上传、下载以使用端为视角。本节点所有 TCP / UDP、所有连接共享本节点的对应方向额度；全部节点每方向合计仍不超过 **256 KiB/s（约 2.1 Mbps）**。设置上限不保证实际达到该速度；统计闸门转发字节，不含全部 SSH / SS / IP 封装开销。改限速不会更换密码、重启 GOST 或要求朋友重装。

链接和 YAML 都含节点密码。查看对话框关闭、页面切换后台、退出或发现凭据过期后会清空页面字段；不会写 localStorage。已下载文件和已复制内容不会自动删除。

**不再运行旧连接器 / 接收器，也不再导出 JSON 连接卡。** 旧连接器的本机 `11081/11082/11083` 不再是本服务的使用方式。

## 密码与节点状态

- 节点密码与管理面板口令分开；支持手动输入或生成高强度独立 SS 密码。
- 自定义密码 8–128 个字符，不包含换行 / 控制字符，需两次输入一致；拒绝当前密码和本功能记录的近期旧密码（每节点最多保留 64 条 HMAC 指纹，不保存历史明文）。
- 自定义密码使用服务器已有 `cryptography 41.0.7` 的 Fernet 认证加密存储，每节点 / 每版本派生独立存储密钥。数据库损坏时不回落成另一个密码；原随机密钥的派生保持不变。
- 原有节点的身份、备注、启用状态、密码版本和朋友授权完整保留；V4.1 / V4.2 发布均保留用户已更换的第 4 版，没有为测试重置生产密码。
- 原接收器中人工输入的“使用密码”已退役，不是新标准 SS 密码。以面板显示 / 导出的参数为准。
- 更换密码 / 撤销会提高服务端凭据版本、断开本节点旧连接；不重启其他节点监听器。
- 闲置 / 停用立即停止该节点流量，出口端仍可报到；离线超过 45 秒不允许建立或继续转发流量。
- 当前只开通 slot 0 的 `24443/TCP+UDP`。新朋友仍自动出现在面板，但其独立端口要单独配置 Ubuntu 和阿里云防火墙，并加入服务端 `direct_open_slots`；未开通前不会导出不可用的配置，也不批量开放空闲端口。容量 32 不代表提前开放 32 个公网端口。

## 链路

```
SSTap / FlClash
  → 标准 Shadowsocks aes-256-gcm（TCP + UDP）
  → 203.0.113.20:24443
  → 节点状态 / 代次鉴权 / 节点与总限速 / 公网目标校验闸门
  → 朋友主动建立的 SSH 反向通道
  → 朋友物理网卡 / 宽带出口
```

客户端至服务器使用标准 SS AEAD 加密，不是裸 SOCKS5、HTTP 或之前的 mTLS 自定义入口。服务器至朋友仍使用现有 SSH 加密通道。UDP 在第一段是真正的标准 SS UDP，服务器至朋友通过既有 GOST UDP-over-TCP / SSH 承载，可能受 TCP 队头阻塞影响，不等同于 UDP 全程直连。

V4.2 根据用户确认加固目标校验：TCP 连接和 UDP-over-TCP 的每个目标均须是公网地址；拒绝私有 / 共享 / 回环 / 链路本地 / 元数据 / 组播 / 保留 / 地址转换前缀及服务器自身 IP。域名由中转服务器检查全部解析结果，混入内网答案即拒绝，再固定允许的数字 IP 发给朋友，不让朋友二次解析产生重绑定绕过。部分域名的就近解析可能因此变化；无法解析时拒绝，不回落服务器直出。不能用本服务访问朋友路由器或内网设备。

- 原 V1 `gost-home-relay.service` 和旧 V2 `home-relay-v2-proxy.service` 已停止、取消启用并 mask；只保留同一 GOST 可执行文件供新服务使用。
- `24443` 被重新用于 SS，不是遗留闲置端口；阿里云仅新增用户确认的 UDP 24443，原 TCP 24443 继续使用。
- 旧 `18783` 回调、空闲 `23001–23031/25001–25031` 不再监听；`22000/23000/25000` 为当前朋友反向通道、内部闸门和检测前端，仍必须保留，仅监听 loopback。

- 不删除用户旧版本 / 历史文件，不终止用户已有 Edge 工作窗口，不更改系统代理、TUN、路由、FlClash 或全站业务数据库。
